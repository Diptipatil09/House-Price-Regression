# House Price Prediction using Regression

## Overview

This project implements regression models for predicting house prices. It also implements Gradient Descent optimization for Linear Regression.

## Models Used

- Linear Regression
- Linear Regression using Gradient Descent
- Polynomial Regression

## Features

- Area
- Bedrooms
- Bathrooms
- Age of House

## Evaluation Metrics

The models are evaluated using:

- MAE
- MSE
- RMSE
- R² Score

## Technologies Used

- Python
- NumPy
- Pandas
- Matplotlib
- Scikit-learn
